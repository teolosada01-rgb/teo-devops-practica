# teo-devops-practica

**Autor:** Teo Losada Gándara

## Descripción

Aplicación Python de una tienda online desarrollada en la asignatura Arquitectura del Software. Gestiona usuarios (clientes y administradores), productos (genéricos, electrónicos y de ropa) y pedidos con control de stock.

La lógica de negocio se expone como una API REST con FastAPI y se puede usar desde la documentación interactiva `/docs`, desde un cliente Python con `requests` o desde un frontend web.

En este repositorio se irá viendo la evolución del proyecto: control de versiones con Git y GitHub, y su contenerización con Docker.
